# ADR-0002: Manuelle Dependency Injection

Status: angenommen (13.10.2026)

Kontext: Hilt/Dagger und Room brauchen KSP; mit AGP 9 (eingebautes Kotlin) und Kotlin 2.4 ist das in einer Umgebung ohne lokales Bauen ein unnötiges Risiko.

Entscheidung: Konstruktor-Injektion über einen `AppContainer` (in `OrbitApp`), ViewModels über eine kleine Factory.

Folgen: keine Codegenerierung, volle Kontrolle, etwas mehr Handarbeit bei neuen Abhängigkeiten.
